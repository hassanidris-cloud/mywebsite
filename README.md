# Velora Studio — Brand & Marketing Site

Premium web design agency marketing site. Built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion**.

## Brand kit

- **Primary gradient:** `#7C3AED` → `#A78BFA` → `#38BDF8`
- **Backgrounds:** Dark `#0B0B0F`, Light `#F8FAFC`
- **Typography:** Plus Jakarta Sans (headings), Inter (body)
- **Logos:** `src/components/brand/` — icon, horizontal wordmark

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Favicon

SVG icon is at `src/app/icon.svg`. For multiple favicon sizes (16, 32, 48, 180, 512), add PNG exports to `app/` or use a favicon generator from the SVG.
