## 2. Backend Pricing Logic

Backend work is priced on top of the chosen website tier. Use these as **add-on ranges** (adjust to your market).

| Backend feature | Typical add-on range | Notes |
|-----------------|----------------------|--------|
| **Authentication** (email/password, OAuth, magic link) | $1,500 – $3,500 | Depends on providers and roles |
| **Admin dashboard** (CRUD, basic analytics) | $2,500 – $5,000 | Per entity complexity |
| **Database integration** (design + API + migrations) | $1,500 – $4,000 | Depends on complexity and reporting |
| **API integrations** (third-party APIs, webhooks) | $800 – $2,500 per integration | Per API, including auth and error handling |
| **Booking / scheduling system** | $3,000 – $6,000 | Calendars, availability, notifications |
| **Payments** (Stripe, PayPal, or client’s preferred provider) | $2,000 – $5,000 | One-time setup; scope per region/provider |
| **Multi-tenant or roles** (teams, permissions) | $3,000 – $8,000 | Scales with roles and rules |

**Example price increases (Business tier base $6,000):**

- + Auth (login/signup, 1 role): **+$2,000** → $8,000  
- + Simple admin (manage blog + contacts): **+$3,000** → $11,000  
- + Stripe one-time payments: **+$2,500** → $13,500  
- + Booking (availability + emails): **+$4,000** → $17,500  

Always scope backend features in a proposal (pages, user types, integrations) to avoid scope creep.

## 3. Hosting & Infrastructure

Present these as **optional add-ons** or **included** in maintenance plans.

### One-time / setup

| Item | Typical cost | Notes |
|------|--------------|-------|
| **Domain registration** | $12 – $25/year | Pass-through or small markup |
| **Initial DNS / SSL setup** | Often included in build or first year | — |
| **Deployment setup** (CI/CD, env, staging) | $300 – $800 one-time | Or bundled in build |

### Recurring — by platform (monthly / yearly)

| Platform | Use case | Monthly | Yearly (approx.) |
|----------|----------|---------|-------------------|
| **Vercel** | Frontend / Next.js, serverless | $20 – $150+ | $240 – $1,800+ |
| **Supabase** | DB, auth, storage, edge functions | $25 – $100+ | $300 – $1,200+ |
| **AWS** (e.g. Amplify + RDS/Lambda) | Full control, compliance | $50 – $500+ | $600 – $6,000+ |
| **Cloudflare** (Pages + Workers + D1) | Global edge, low cost | $20 – $100+ | $240 – $1,200+ |

**Suggested client-facing hosting bundles (monthly):**

- **Starter** (static/simple): $25 – $40/mo (e.g. Vercel Pro + form service)  
- **Business** (CMS + DB): $60 – $120/mo (e.g. Vercel + Supabase or headless CMS)  
- **Premium** (app + DB + auth): $120 – $250/mo (e.g. Vercel + Supabase/AWS, monitoring)  

Offer **yearly pricing at a discount** (e.g. 2 months free) to improve cash flow and retention.

## 7. Business Optimization

### Increase profit margins
- **Productize** — fixed-scope packages (Starter / Business / Premium) reduce scope creep and sales time.  
- **Templates & components** — reuse layouts and components across projects to cut build time.  
- **Clear change-order process** — “Out of scope” work is quoted separately; small buffer (e.g. 10–15%) on fixed-price builds.  
- **Premium positioning** — target clients who value quality and speed; avoid competing on price alone.

### Upsell backend features
- **Discovery call checklist** — ask about “member areas, dashboards, payments, booking” and map to add-ons.  
- **Proposal line items** — list “Optional add-ons” (auth, admin, payments) with prices so clients can say yes later.  
- **Phase 2** — “Launch now with core features; add dashboard/payments in Phase 2” to secure the first project and recurring work.

### Package hosting + maintenance
- **Care plan** — “Hosting + Basic Maintenance” as one monthly price (e.g. $199/mo) so clients don’t manage vendors.  
- **Annual prepay** — 10–15% discount for yearly payment to improve cash flow.  
- **Tiered care** — Basic / Business / Premium support aligned with website tier and client size.

### Scale from freelancer to agency
- **Document everything** — this pricing system, proposal templates, and scope templates.  
- **Subcontract or hire** — use the same tiers and add-ons so others can deliver; you sell and manage.  
- **Retainers** — move from one-off projects to monthly retainers (maintenance + feature hours).  
- **Productized services** — “Starter in 4 weeks” or “Business in 6–8 weeks” with fixed process and handoff.  
- **Pricing power** — as you add case studies and referrals, gradually increase rates within each tier.
